# Site rules: Example Guides (fictional)

These rules override `prompts/writing-rules.md` for this site only. The truth rules (no invented facts, no cloaking) always apply.

## Owner

- We make Northwind Notes (fictional). It may appear in lists, ranked by the same criteria as every other app.
- Spell it "Northwind Notes". Never "NorthWind" or "Northwind Note".

## Ranking

- Rank by the criteria in each page's "How we chose" section. Northwind Notes is not #1 by default.

## CTA

- Label: "Try Northwind Notes". Link: `{{cta_url}}`.
- Other links to the owner's site use `{{utm:https://example.com/northwind}}`.

## Claims

- Price: "free for one user". No other prices for Northwind Notes.
- No ratings, review counts or customer names.

## Disclosure

- Use the disclosure in `site.json` on every page that lists Northwind Notes.
